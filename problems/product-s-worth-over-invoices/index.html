1677. Product's Worth Over Invoices

Intuition & Approach

To solve Product's Worth Over Invoices efficiently, we can use standard algorithms and data structures. Explaining the logic, time complexity, and space complexity here will help you understand the solution better.

Code Solution

SQL
SELECT
  Product.name,
  IFNULL(SUM(Invoice.rest), 0) AS rest,
  IFNULL(SUM(Invoice.paid), 0) AS paid,
  IFNULL(SUM(Invoice.canceled), 0) AS canceled,
  IFNULL(SUM(Invoice.refunded), 0) AS refunded
FROM Product
LEFT JOIN Invoice
  USING (product_id)
GROUP BY 1
ORDER BY 1;
