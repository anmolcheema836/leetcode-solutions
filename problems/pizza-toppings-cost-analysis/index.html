3050. Pizza Toppings Cost Analysis

Intuition & Approach

To solve Pizza Toppings Cost Analysis efficiently, we can use standard algorithms and data structures. Explaining the logic, time complexity, and space complexity here will help you understand the solution better.

Code Solution

SQL
SELECT
  CONCAT(T1.topping_name, ',', T2.topping_name, ',', T3.topping_name) AS pizza,
  ROUND(T1.cost + T2.cost + T3.cost, 2) AS total_cost
FROM Toppings AS T1
INNER JOIN Toppings AS T2
  ON (T1.topping_name < T2.topping_name)
INNER JOIN Toppings AS T3
  ON (T2.topping_name < T3.topping_name)
ORDER BY total_cost DESC, pizza;
