2199. Finding the Topic of Each Post

Intuition & Approach

To solve Finding the Topic of Each Post efficiently, we can use standard algorithms and data structures. Explaining the logic, time complexity, and space complexity here will help you understand the solution better.

Code Solution

SQL
SELECT
  Posts.post_id,
  IFNULL(
    GROUP_CONCAT(
      DISTINCT Keywords.topic_id
      ORDER BY Keywords.topic_id
    ),
    'Ambiguous!'
  ) AS topic
FROM Posts
LEFT JOIN Keywords
  ON (CONCAT(' ', LOWER(Posts.content), ' ') LIKE CONCAT('% ', LOWER(Keywords.word), ' %'))
GROUP BY 1;
