2077. Paths in Maze That Lead to Same Room

Intuition & Approach

To solve Paths in Maze That Lead to Same Room efficiently, we can use standard algorithms and data structures. Explaining the logic, time complexity, and space complexity here will help you understand the solution better.

Code Solution

Python
class Solution:
  def numberOfPaths(self, n: int, corridors: list[list[int]]) -> int:
    ans = 0
    graph = [[False] * 1001 for _ in range(n + 1)]

    for u, v in corridors:
      graph[u][v] = True
      graph[v][u] = True

    for u, v in corridors:
      for i in range(1, n + 1):
        if graph[u][i] and graph[i][v]:
          ans += 1

    return ans // 3
