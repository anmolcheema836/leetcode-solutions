1369. Get the Second Most Recent Activity

Intuition & Approach

To solve Get the Second Most Recent Activity efficiently, we can use standard algorithms and data structures. Explaining the logic, time complexity, and space complexity here will help you understand the solution better.

Code Solution

SQL
WITH
  RankedUserActivity AS (
    SELECT
      *,
      COUNT(*) OVER(PARTITION BY username) AS `count`,
      RANK() OVER(
        PARTITION BY username
        ORDER BY endDate DESC
      ) AS `rank`
    FROM UserActivity
  )
SELECT
  username,
  activity,
  startDate,
  endDate
FROM RankedUserActivity
WHERE `count` = 1 OR `rank` = 2;
