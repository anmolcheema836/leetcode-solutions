1596. The Most Frequently Ordered Products for Each Customer

Intuition & Approach

To solve The Most Frequently Ordered Products for Each Customer efficiently, we can use standard algorithms and data structures. Explaining the logic, time complexity, and space complexity here will help you understand the solution better.

Code Solution

SQL
WITH
  RankedOrders AS (
    SELECT
      Orders.customer_id,
      Orders.product_id,
      Products.product_name,
      RANK() OVER(
        PARTITION BY Orders.customer_id
        ORDER BY COUNT(Orders.product_id) DESC
      ) AS `rank`
    FROM Orders
    INNER JOIN Products
      USING (product_id)
    GROUP BY 1, 2
  )
SELECT
  customer_id,
  product_id,
  product_name
FROM RankedOrders
WHERE `rank` = 1;
